# 输入资料

简历、JD、掌握状态是 UTF-8 文本，通过命令行传入路径。

## 本地脱敏简历

`resume.anonymized.md` 是基于最近一次真实面试所用简历制作的脱敏副本。
源文件为 Go 项目的 `../mockinterview/inputs/resume.md`，原件未修改。

- 删除姓名、联系方式、年龄、性别、学校名称及具体日期。
- 将公司、产品和内部组件名称替换为通用描述，将精确业务指标概括为量级。
- 保留岗位职责、技术栈、迁移经历与业务约束，不新增未经确认的项目实现。
- 仍保留个人经历和技术组合，不保证无法关联到本人；发给外部服务前可继续删减。

新建面试时传入 `--resume-file inputs/resume.anonymized.md`。
这是输入文件替换，不会更新旧会话的 checkpoint、调用记录或已有报告；
用 `resume` 恢复旧会话时，仍会使用旧会话保存的原始资料。

JD、掌握状态也可以直接引用旧项目的文件，但它们**不在本次脱敏范围内**；
如果也包含身份或业务细节，需要单独检查。运行时新提交的回答同样会发送给模型服务。

个人输入文件默认不进入版本管理。`demo-answers.txt` 仅为离线流程测试样例，
答案以独立行 `===ANSWER===` 分隔；空文件代表立即暂停，不会提交空答案。
